# Sentinel AI

Community-driven safety intelligence platform — real-time incident reporting 
with automated credibility scoring and live area-based risk assessment.

## Features
- **Community Reports** — live Supabase-backed incident reporting
- **Trust Scoring** — automatic credibility scoring based on report corroboration
- **Live Risk Score** — severity-weighted area risk aggregation
- **Time-of-Day Forecast** — risk elevation modeling for night hours
- **Dashboard** — real-time KPIs computed from live report data

## Tech Stack
React, Vite, TypeScript, Supabase (Postgres + Storage + Realtime), Tailwind CSS
